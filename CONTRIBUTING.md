# Contributing to Vidoza

Thank you for your interest in contributing to **Vidoza**!

## How to Contribute

1. **Open an issue first** for major changes, new platform integrations, or architectural proposals so we can discuss the approach.
2. **Fork** the repository and create a feature branch from `main`:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. **Keep PRs focused** — one feature or bug fix per pull request.
4. **Never commit secrets** — keep `.env`, `*.db`, OAuth tokens, and local editor files out of git.
5. **Test locally** before opening your pull request (`npm start` and verify affected flows).

## Areas Where Help Is Welcome

- Additional languages and neural voices in `src/languages.js`
- New stock media or TTS providers
- Remotion subtitle styles and video templates
- Documentation improvements and bug fixes
